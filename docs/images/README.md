# README illustrations

These repository assets are the two desktop screenshots supplied by the project
maintainer for the README. They show the four-aircraft mission editor and native
PX4/Gazebo simulation side by side, without depending on ignored run artifacts
or files outside the repository.

- `planner.png` shows the editor in Mission view with the physical C++ planner,
  four aircraft, a shared target and three obstacles. Original source:
  `/home/anto/Pictures/Screenshots/Screenshot from 2026-10-30 17-55-17.png`.
- `gazebo.png` shows the Gazebo interface, aircraft models, static obstacles and
  colored 3D spatial-reference visuals. Original source:
  `/home/anto/Pictures/Screenshots/Screenshot from 2026-10-30 17-56-48.png`.

Both PNGs are copied without modification at their original 1854 × 1048
resolution. The README displays them at equal widths and links each image to
the full-resolution asset.

The colored Gazebo visuals are planned references, not measured flight trails.
The screenshots illustrate the workflow and do not establish successful flight
validation. Native PX4 execution does not inherit the point-mass planner's timing
or separation claims.

# README illustrations

These committed assets show the four-aircraft PX4/Gazebo workflow. The images
remain available independently of ignored run artifacts or external video hosting.

- `gazebo.png` is an unmodified native Gazebo screenshot, including its rendered
  ground, obstacles and colored spatial-reference visuals. Source:
  `results/px4-gazebo-fleet/20261028-140507-860464/2026-10-28T13:06:06.244330951.png`.
  That archived four-aircraft SITL run completed its experiment gates and landing
  checks. Its reference used the historical geometric/Python generator; the
  screenshot is an illustration, not a new C++ flight qualification. Mission
  SHA-256: `abb4e591d3c287a7a179168a5eef9364594fd914c0ecfa8dbb4d7859101d4481`.
- `planner.png` is the current Gazebo preparation editor in Mission view,
  rendered directly through `edit_scenario(..., profile_loading=False)` with
  `examples/scenarios/px4_four_loiter_cpp.json`. It shows the current physical/C++
  selection and the same illustrated fleet layout, target and three obstacles.
  The reference paths generated by the two planner versions are not asserted
  to be identical.

The native screenshot is not a Matplotlib flight plot or an AI-generated image.
The colored Gazebo visuals are planned spatial references, not measured flight
trails. Native PX4 execution does not inherit the point-mass planner's timing
or separation claims; no real-aircraft flight is depicted.

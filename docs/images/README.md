# README illustrations

These curated documentation images depict the same four-aircraft mission.
They are committed so the repository README does not depend on ignored run
artifacts or external video hosting.

- `planner.png`: the current `ScenarioEditor` Mission view, rendered with the
  saved initial snapshots and configuration.
- `simulation-3d.png`: a Matplotlib 3D still from the saved point-mass execution
  telemetry at 30 s. Solid paths are executed prefixes; dashed paths are nominal
  references through the latest arrival plus six seconds. All four aircraft
  markers use recorded positions. The altitude scale is exaggerated for clarity.

Source run: `results/cpp-default-20261030/default-cli/`, generated by
`examples/trajectory_3d.py --no-gui` with the default four-aircraft physical/C++
configuration. Planning and execution are recorded as validated. Original
mission SHA-256: `41aa107df9e1e427b6616fcca1d393c619351e82071e1802f0d9c16405882888`.

The editor is rendered from its actual Python widgets; the simulation image is
rendered from exported trajectories and telemetry. These are not PX4/Gazebo
screenshots or evidence of real-aircraft flight. Full-horizon validation and
saved mission data are unchanged by the illustrated display interval.
